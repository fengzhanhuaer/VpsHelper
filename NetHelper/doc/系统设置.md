# NetHelper 配置与升级功能实现方案

## 功能目标
增强 NetHelper，支持持久化配置（`./data/config.json`），在设置界面中增加 `SecretKey`（密码格式）和 `ServerUrl`。参照 `vpsprobe` 的机制实现 NetHelper 的升级功能（支持通过 Yamux 流从主控节点进行直连下载和代理下载）。

## 验证与测试方案

### 自动化 / 构建测试
- 在 `NetHelper` 目录下运行 `wails build`，验证代码是否能正常编译且无语法错误。

### 手动验证
- 启动 `NetHelper`，进入“设置”页面，输入主控节点 URL 和对应 Secret Key 并点击“保存”。
- 检查应用运行目录下是否成功生成了 `./data/config.json` 文件。
- 在“设置”页面的“检查更新”一栏中，勾选“通过代理服务器检查/下载”或“直连检查/下载”。
- 点击“检查新版本”按钮。程序应正确判断当前版本以及获取最新 Release 的能力。
- 点击“执行版本更新”。程序应按所选的网络路径下载、进行内部预检，并在成功覆盖可执行文件后自动重启。
