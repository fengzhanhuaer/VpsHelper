# 🤖 Telegram 深度联动指北：告警通知与 Userbot 矩阵

VpsHelper 内置了一套极具极客风格的 Telegram 综合系统它主要包含两大核心板块：**被动事件告警通知 (TG Bot)** 与 **主动化的并发智能客户端 (Userbot 矩阵)**。此模块能够满足您对群组管理、服务器离线预警乃至多号挂机监控等全方位需求。

---

## 🔔 第一部分：系统的基础通知告警 (Telegram Bot)

当您的 VpsProbe（探针）出现宕机离线、自动签发续订 TLS 证书成败、或拨测监控发现路由阻断时，系统可以通过您自己的私人 Bot 发给您推送消息。

### 配置流程
1. 打开 Telegram，搜索并进入 `@BotFather`，并向其发送指令 `/newbot` 创建一个全新的机器人，获得一串 `Bot Token` (例如 `123456:ABC-DEF1234ghIkl-zyx5c`)。
2. 搜索并关注 `@userinfobot`，或发任意消息向您自己的新机器人，得到一个形如 `123456789` 的 **您的个人 Chat ID**。
3. 登录 VpsHelper 面板，进入 **[Telegram 任务] -> [TG 发信及通知 Bot]** 菜单。
4. 填写刚刚获取的 `Bot Token` 与你的个人接收 `Chat ID`，点击保存测试。收到测试回执即证明连通成功。

> **⚠️ 网络连通性提示 / 代理设置**
>由于原生的 `api.telegram.org` 域名在部分境内受限的服务器网络中被阻断（DNS污染或SNI重置），面板内部贴心地提供了 **[TG全局代理设置]**。若您的主控端面版部署在境内，请前往面板通过 **代理配置** 指定能连通国际网络的 `SOCKS5` 或 `HTTP` 端点。

## 🤖 第二部分：并发级 Userbot 会话托管 (MTProto)

告别需要常驻电脑挂机运行 Python `Telethon/Pyrogram` 老脚本的日子。VpsHelper 原生级搭载了 Google Go 所编写的 `gotd/td` 强依赖低级库，能够直接连接 Telegram MTProto 数据中心，并在远端 Web 面板替你 **全天候肉身登录你真正的账号**！

### 核心特性
- **无限状态矩阵**：面板后台能够拉起多个长连协程，容纳同时登录管理多个不同的手机号 Telegram 身份（大号、小号）。
- **极低的开销**：单会话状态约占用仅不到 5MB RAM。

### 📌 如何登入一个 Userbot 账号？
1. 若要使用原生的 MTProto，用户需前往 [my.telegram.org](https://my.telegram.org) 申请个人开发应用，获取专属的 `API_ID` 与 `API_HASH`。
2. 进入面板中 **[登录TG账号 (Userbot)]** 界面。
3. 输入手机号码 (例如 `+8613800000000` 或 `+1xxx...`) 发起登录。
4. 面板会同步回调显示 Telegram 官方账号下发给您的 **5位数验证码框 (与二次两步验证 2FA 密码输入框)**。输入后，该会话文件就会通过 SQLite 永远挂载在了面板内核里。你可以尽情开始使用以下主动功能：

## ⚙️ 第三部分：Userbot 的杀手级应用流

有了长驻在后台处于“Online”状态的个人 TG 账号身份，你可以进入 **[TG 高级操作]** 玩出极多花样操作：

### 1. 自动回复防卫 (Auto Reply)
您或您的机器人所在的群组常常会碰到固定的新人提问或广告？又或是你正在度假，想针对私人对话提供假期的默认“不在”提示？
- 你可以在面版创建一条正则规则关键词 (例如包含 `求助` 、`菜单`)。
- 选择生效的对象：可以是特定群组，或者是针对所有人的私聊。
- 当有用户触发，Userbot 将以你在手机上打字的同样名义瞬间弹出你设定好的回复文本。

### 2. Cron 级定时自动发信 (Auto Send)
作为运营者，常需准点在数十个推广群里散播图文广告？或者半夜零点自动触发签到机器人？
- 进入面板内的 **[自动定时任务发送]**。
- 您可以指定某个频道、群组，甚至是个人对话框。
- 录入欲要发送的多行图文内容。
- **自定义 Cron 表达式调度器** (如 `0 30 8 * * *` 意为每天上午8点半推送，或 `*/15 * * * *` 意为每 15 分钟循环发条内容轰炸群组)。彻底告别手工劳动。
