# 🛡️ 深度运维管控：防火墙安保与原生 Shell

VpsHelper 旨在将沉重的运维工作大幅度简化，直接将日常高频使用的系统级功能搬到了 Web 控制面板中。这里详细介绍两大底座管控利器：**UFW 软防火墙联动** 与 **在线原生 Web Shell**。

---

## 🧱 一、UFW / Linux 软防火墙管理

当你的服务器暴露在公网上时，每天都会遭受数以万计的僵尸网络端口扫描和 SSH 密码暴力破解。VpsHelper 提供了直观且强大的本机防火墙防护功能。

### 1. 通用封堵与放行策略
无需每次 ssh 进去敲打繁杂的 `iptables` 或 `ufw` 命令，你可以直接在控制面版的 **[安全防护 & 防火墙]** 中进行统筹：
- 提供一张全景视角的服务器白名单视图（包含 IPv4 和 IPv6）。
- 支持一键下发指令在底层系统中开启 UFW，并将特定的恶意 IP 彻底在这个操作系统的流量入口处进行 Drop 丢弃。
- 可以配合面板内置的探测逻辑，看到当前机器上有哪些 IP 正在进行异常的高频链接。

### 2. 自动化防爆破与端口隐蔽
你可以配合面板一键修改默认的 `Port 22`。配合 VpsHelper 的定时查杀机制，如果某些 IP 在主机的 `auth.log` 留下了过多的认证失败记录（说明正在暴力尝试密码），面板可以配合防火墙自动将其封杀。

### 3. 与 Cloudflare WAF 双剑合璧
不仅是单机防火墙，在面板另一侧的 **[Cloudflare BlockList]** 中如果录入了某个高风险网段，你会将这层过滤网直接向上拉到最前端的 CDN 边缘层。当攻击流量还未抵达你机房所在的母鸡上时，就已经在 Cloudflare 的服务器上被拒绝！做到 **主机系统层防火墙 (UFW)** + **云防护盾层 (WAF)** 的双轨拦截。

## 💻 二、全功能 Web Terminal (免密原生 Shell)

以往管理大量探针需要维护一份冗长的 SSH 配置表，或者忍受使用一些第三方 WebSSH 平台带来的安全隐患（需提供 root 密码或私钥）。

VpsHelper 是直接扎根在宿主机系统的底层管理服务进程，意味着：

### 1. 安全的原生降权/提权交互
无需在外部保存密码和密钥验证。只要你在 VpsHelper 面版具备管理员 Web 鉴权，即可：
- 顺滑点开面板内置的 **[在线 Shell 工具]**，VpsHelper 后端会依托 Go 自带的原生 `pty` 直接与底层的 Bash / Zsh 接驳，直接输出。
- 你看到的是无任何延迟的、享有完整控制台颜色转义及历史记录翻查的原生 TTY。甚至由于系统守护进程多数以 root 存在，你可以直接获得最高系统特权来执行紧急救援命令。

### 2. 多机并行执行 (Pipeline 广播)
当你在架构内挂载了 3 台不同国家地区的探针节点。你可以：
- 不用分别登录三台机器逐个执行安装依赖。
- 在面版的 **快捷命令库 (Shortcuts)** 中将一长段命令固化为一个预定义按钮。
- 直接选择将这条预配的命令（如下发定时重启更新源：`apt-get update -y && reboot`）下发推向特定集群，让子节点静默执行并返回执行结果日志给你，极大提升管理数十台小鸡的运维愉悦感。
