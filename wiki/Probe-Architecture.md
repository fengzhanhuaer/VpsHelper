# 🚀 探针节点拓扑与拔测结构

我们的 “主-副” 节点架构是一套高度自治轻量的 WebSocket 双向全双工安全通讯协议网。主节点 (Master) 即您的主要 Web 面板服务器，可以动态派生无限数量的分支受指派机器 (VpsProbe) 加载业务。

## 一、服务器状态大屏监控 (实况仪表)
- 所有接入探针的子机会自动在挂载起的第一秒种持续上报宿主机的内存利用率 (RAM)、中央处理器满负荷率 (CPU)、物理磁盘硬盘存量 (Disk Space)。
- 探针端以高效率每秒采集机器的网络带宽物理上下行瞬发速率，供主控端呈现出动态滚动的实时高频流瀑布型图表。
- 面板即时标识每台服务器与核心网络的通讯延时、离线宕机、重新排队重连以及恢复健康状态流向。

## 二、分布式任务拔测中心 (Distributed Ping)
告别单点数据无法呈现网络跨大洋的路由表现——VpsHelper 可以在 Web 控制台中将某个目标 (如一个境外游戏服务器的新 IP 或站点域名)，**作为发往特定探针池的探针任务**。

- 受控分支接收任务后，将全天候周期循环地以自定频率直接在此终端发起 ICMP Ping 包反馈。
- 所有的数据交由中心 `probe_data.db` 时间序列归档结构写入缓存中。
- 大屏终端将拉取这部分带有时间序列的基准图表并主动绘制展示你每台受控 VPS 最近 24 小时的线路历史连通性、丢包率、以及尖峰延宕（比如从洛杉矶节点拨测到日本，以及从香港节点拨测到日本的完全不同的物理波形比较）。

## 三、静默下发重启更新 (零感知更新)
随着你在主干上更新配置和升级 Github 的代码库，再也不需要去每台受控服务器上逐一敲命令。您可以极其方便地通过 Web 控制页面：
1. 发出一键升级指尖：触发广播全管辖节点子机器自动热拉最新适配自身操作系统的探针架构。
2. 配置节点降级容灾连接地址，令探针一旦失联立刻按降级顺序寻址。
